## 1. 商品详情（Store listing）

**语言：** 中文（简体）

**名称：** 由 zip 包里的 manifest 自动读取 → `互关检测助手 for X`

**摘要：** 由 manifest 自动读取 →
```
查看 X（Twitter）上谁取关了你：找出曾经互关、后来取关你的账号，区分真取关与账号受限，并可分批取关。非 X 官方产品。
```

**说明（Description）：**
```
想知道谁悄悄取关了你？「互关检测助手 for X」帮你找出曾经和你互关、后来取消关注的账号。

【主要功能】
• 取关了我：列出曾经互关、后来取关你的账号，并记录发现时间
• 区分真取关和账号异常：被 X 限制的账号（主页显示「此账号暂时受限」）、清空了全部关注的账号会单独标出，不会被误判成取关
• 未回关：列出你关注了、但没有关注你的账号
• 默认只看蓝V（已认证账号），也可以查看全部，支持搜索和按粉丝数排序
• 扫描速度快：一千多个关注十几秒就能扫完
• 结果保存在本地，打开面板就能看，不用每次都重新扫描
• 不想取关的账号可以「忽略」，以后不再显示
• 支持导出 CSV
• 点工具栏图标一键开启 / 关闭，关闭时页面上不显示任何内容

【使用方法】
1. 在 x.com 登录你的账号
2. 点工具栏上的插件图标开启，再点页面右下角的浮窗按钮
3. 点「开始扫描」。第一次扫描会记下当前和你互关的人，以后再扫描就能找出取关了你的人

【安全与隐私】
• 所有数据只保存在你自己的浏览器里，插件没有服务器，不上传任何数据
• 只有在你点击「取关」并确认后，插件才会执行取关
• 批量取关会自动间隔 3–7 秒，并在连续失败时自动暂停

【提醒】
X 的规则禁止短时间内大量取关。请控制数量（建议每天不超过 50–100 个），以免账号受到限制。

本插件是个人开发的工具，不是 X Corp. 的官方产品，与 X Corp. 无关。
开源地址：https://github.com/lonly2010/x-mutual-checker
```

## 2. 隐私权（Privacy practices）

**单一用途说明（Single purpose）：**
```
帮助用户查看自己的 X（Twitter）账号中，哪些账号曾经互相关注、后来取消了关注，并让用户自行决定是否取关这些账号。
```

**权限理由 —— storage：**
```
用于在用户的浏览器本地保存扫描结果、历史互关名单、用户设置为「忽略」的账号，以及插件的开关状态和浮窗位置。这些数据不会离开用户的设备。
```

**权限理由 —— 主机权限（x.com、twitter.com）：**
```
插件只在 x.com 和 twitter.com 上运行：在页面上显示插件面板；使用用户已有的登录状态读取用户自己的关注列表；在用户点击「取关」并确认后，向 X 发送取消关注的请求。插件不访问任何其他网站。
```

**是否使用远程代码（Remote code）：** 选「**否，我没有使用远程代码**」
> 说明（如果需要填写）：插件的全部代码都在软件包里。插件会读取 x.com 页面已加载的脚本文本，用来查找关注列表接口的编号字符串，但不会执行这些文本。

**数据使用（Data usage）：**
- 「此扩展程序会收集或使用以下哪些用户数据」：**全部不勾选**。插件处理的关注列表只保存在本地，不会传输给开发者或第三方。按商店的定义，这不算「收集」。
- 下面三条声明**全部勾选**：
  - 我不会出于已获批准的用途之外的用途向第三方出售或传输用户数据
  - 我不会为实现与我的产品的单一用途无关的目的而使用或转移用户数据
  - 我不会为确定信用度或实现贷款而使用或转移用户数据

**隐私权政策网址：**
```
https://github.com/lonly2010/x-mutual-checker/blob/main/PRIVACY.md
```

## 4. 给审核员的测试说明（Test instructions，如果后台要求填写）

```
1. Install the extension and sign in to any X (Twitter) account at https://x.com.
2. Click the extension's toolbar icon to enable it (the badge shows "开"). A floating button appears at the bottom-right of x.com.
3. Click the floating button, then click "开始扫描" (Start scan). The extension reads the signed-in user's own following list and shows the results in the panel.
4. "取关了我" lists accounts that used to follow back but no longer do (available from the second scan on). "未回关" lists accounts that don't follow back.
5. Unfollowing only happens after the user clicks "取关" and confirms the dialog.
All data stays in chrome.storage.local; the extension has no server.
```
